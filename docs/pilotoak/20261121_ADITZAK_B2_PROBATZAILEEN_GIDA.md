# ADITZAK · B2 · Indikatiboa lehenaldian
## Probatzaileen gida laburra · 2026-11-21

**Egoera:** PROBA KONTROLATUA · **EZ EGIAZTATUA**  
**Norentzat:** administratzaileak banaka hautatutako kontu aktiboentzat bakarrik.  
**Helburua:** ariketetako enuntziatuak, erantzun-proposamenak, azalpenak, zailtasuna eta erabilgarritasuna berrikustea. Ez da azterketa ofiziala, eta ez da ziurtagiririk edo notarik ematen.

### Nola sartu

1. Administratzaileak zure kontua **Probatzailea gaitu** bidez gaitzen du.
2. Ireki administratzaileak partekatu dizun **Vercel proba-esteka**. Proba-esteka horrek iraungitze-data izan dezake; webeko edukia ikusteko ere SUSTRAIn saioa hasi behar duzu.
3. Joan **Ariketak → B2 → Aditzak → Indikatiboa lehenaldian** atalera.
4. Aukeratu sei jardueretako bat. Ohar hau ikusiko duzu: **PROBA KONTROLATUA · EZ EGIAZTATUA**.

### Probaren urratsak

1. Irakurri ariketaren azalpena eta, beharrezkoa bada, testuinguru osoa.
2. Erantzun ahalik eta modu autonomoenean, laguntzarik gabe.
3. Sakatu **Erantzunak gorde eta proposamenak ikusi**. Erantzunak gordetzen dira, baina ez da kalifikaziorik ezartzen.
4. Konparatu zeure erantzuna behin-behineko ereduekin. **Eredu horiek ere okerrak izan daitezke**; horregatik egiten dugu auditoria.
5. Erabili galdera bakoitzeko **Ohartarazi zalantza edo akatsa** aukera: hautatu kategoria eta larritasuna, azaldu arazoa eta, nahi baduzu, proposatu zuzenketa.
6. Errepikatu ariketa nahi izanez gero. Saiakera eta ohar bakoitza bereizita gordetzen da.

### Zer jakinarazi

| Kategoria | Erabili honetarako |
|---|---|
| Arau-akatsa | Iturri fidagarri batekin egiazta daitekeen arau-haustea |
| Aldaera onargarria | Ereduak baztertzen duen forma zuzena edo erabilera legitimoa |
| Beste erantzun bat | Testuinguruan defendagarri den beste aukera |
| Azalpena | Arrazoibidea oker, osatugabe edo iluna denean |
| Zailtasuna | Mailari edo ataza motari egokitu gabe dagoenean |
| Erabilgarritasuna | Nabigazioa, instrukzioa edo jarduera ulertzea zaila denean |
| Arazo teknikoa | Gordetzeak, pantailak edo botoiek huts egiten dutenean |
| Bestelakoa | Aurreko kategorietan sartzen ez den oharra |

**Arreta berezia jarri:** `bi`, `hiru` eta antzeko zenbatzaile zehaztu mugagabeekin singular/plural komunztadura onargarria izan daiteke. Ez proposatu debeku absoluturik iturri kontrastatu gabe. Bereizi benetako arau-akatsa eta estilo-hobespena.

### Ahozko ariketari buruz

Uneko pilotuak **ez du audioa grabatzen**. Idatz daitekeen transkripzioa edo hausnarketa **ez da** ahoskeraren, jariotasunaren edo ahozko gaitasunaren ebidentzia nahikoa. Erregistratu muga hori aurkitzen baduzu.

### Pribatutasuna eta argitalpen-egoera

- Ez idatzi datu pertsonal sentikorrik, pasahitzik edo hirugarrenen identifikazio-daturik oharren barruan.
- Zure saiakerak eta oharrak Supabasen gordetzen dira. Administratzaileak oharrak ikus ditzake auditoretza kudeatzeko.
- Probalarien iritziak **ez dira automatikoki Euskaltzaindiaren edo irakaslearen onespen akademiko bihurtzen**.
- Ikuskatzaileak oharrak sailkatu, onartu, baztertu edo itxi ditzake, erabakiaren arrazoia gordeaz. Horrek ere ez du ariketa automatikoki egiaztatzen.
- Administratzaileak sarbidea kentzen badizu, ezin izango duzu berriro pilotuko materiala ireki. Aurretik bidalitako froga eta erabakiak historikoan gera daitezke.
