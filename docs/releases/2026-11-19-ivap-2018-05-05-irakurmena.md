## 3. Bi zalantza, ezkutuan eta gako ofiziala aldatu gabe

[GitHub issue #60 · `FROGA_ESKASA` bi itemetan](https://github.com/antoniourutz-dev/sustrai-irakurmena/issues/60).

**20. itema — C gako ofiziala.** «Zer hartzen du funtsezkotzat Rainhornek auziari aurre egiteko?» Testuko «funtsezkoa» medikuek giza gorputzaren salerosketa-merkatuaren **funtzionamenduan** duten esku-hartzeari dagokio, eta «Hipokratesen zina ahaztu» dutela kritikatzen du. C aukerak medikuek zin egindako printzipioak ez arbuiatzea eskatzen du, eta galderak auziari aurre egiteko irtenbidea. Interpretazio normatiboa ulergarria da, baina ez dago konponbide zehatz gisa formulatuta. **C mantendu; `draft`, `published_at=null`.**

**21. itema — C gako ofiziala.** Iturriak negozio erraldoia «legalitate barruan eta kanpoan» aldi berean ari dela dio; C aukerak «legalitatearen eta ez-legalitatearen arteko **muga oso estua**» adierazten du. Bi esparruetan jardutea eta muga juridikoa estua izatea ez dira sinonimo literalak; inferentziaren baliozkotasuna aztertu behar da. **C mantendu; `draft`, `published_at=null`.**

**Ez dira aldatu** IVAPen jatorrizko `sustrai_private.sr_answer_keys`, `public.sr_items.options` edo galderen enuntziatuak. Ez da IVAPen gako alternatiborik ofizialtzat onartu. Zalantzazko azalpenak egile-interpretazio gisa deskribatu dira eta giza auditoriarako erregistratu.
